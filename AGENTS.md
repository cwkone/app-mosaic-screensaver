# App Mosaic Screensaver

Native Swift/AppKit screensaver and preview app. Preserve the existing visual behavior and artwork unless a task requests changes.

## Validation

Run `./Scripts/build.sh` for universal distribution bundles and `./Scripts/test.sh` for model, artwork, catalog, bundle, and preview checks. Generated `build/`, `dist/`, and `QA/` files stay untracked. Distinguish local Intel checks from real System Settings and Apple Silicon device verification.
